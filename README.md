# Коллажный вечер

Лендинг для продажи билетов на коллажный вечер: мини-лекция о коллаже, практика и арт-разбор работ с арт-психологом. 5 декабря, 15:00, 10 мест, 2 000 ₽.

Сайт статичный: обычные HTML, CSS и JS, без сборки и зависимостей. Шрифты и картинки лежат в репозитории, внешних сервисов (Google Fonts и т. п.) нет.

## Структура

```
index.html      — страница и все окна (о Стасе, о Полине, покупка, после оплаты)
css/styles.css  — стили
css/fonts.css   — подключение шрифтов из папки fonts/
js/config.js    — настройки: проданные места, цена, дата, адрес, режим оплаты
js/app.js       — анимации, окна, форма
img/            — фото Стаси и коллажи
fonts/          — шрифты (лицензия SIL OFL)
```

## Что менять чаще всего

Всё в `js/config.js`:

- `seatsTaken` — сколько мест продано. Змейка и надписи «Осталось N мест» считаются от этого числа.
- `price` — цена за место.
- `event` — дата, адрес и название места (адрес используется в ссылке на Яндекс Карты и в файле для календаря).

Тексты меняются прямо в `index.html`. Места, которые ещё нужно заполнить, отмечены квадратными скобками: `[Название]`, `[Фамилия]`, `[@ник]` и т. п.

## Запустить у себя

```
python3 -m http.server
```

и открыть http://localhost:8000.

## Опубликовать на GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через минуту сайт будет по адресу `https://nancymay.github.io/collage_meet/`.

### Свой домен

1. Купить домен (например, в REG.RU или Timeweb).
2. В **Settings → Pages → Custom domain** вписать домен и сохранить: GitHub создаст файл `CNAME`.
3. У регистратора домена добавить DNS-записи:
   - для `вашдомен.ru` — четыре записи `A`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - для `www.вашдомен.ru` — запись `CNAME` на `nancymay.github.io`.
4. Когда DNS обновится (от пары минут до суток), включить **Enforce HTTPS**.

## Оплата через Робокассу

Сейчас стоит `paymentMode: 'demo'`: форма проверяет поля, но деньги не списываются, а после «оплаты» показывается пример окна с подтверждением. **Перед тем как давать ссылку покупателям, нужно подключить настоящую оплату.**

Серверная часть уже готова и лежит в папке [`server/`](server/README.md): она работает внутри того же PocketBase, что и Pokarmanu. Сервер создаёт заказ, держит место 15 минут, принимает уведомление Робокассы об оплате, отправляет письма и сам считает проданные места. Как поставить её на сервер и включить на сайте — в [server/README.md](server/README.md).

После этого в `js/config.js` поставить `paymentMode: 'live'`: сайт начнёт брать число мест с сервера, а `seatsTaken` будет использоваться только если сервер не ответит.

## Персональные данные

Форма собирает имя, почту и телефон, поэтому до запуска нужно:

- хранить заявки на серверах в России (не в Google Таблицах);
- опубликовать политику обработки персональных данных и отдельный документ согласия (ссылка в форме сейчас ведёт на `#oferta`);
- подать уведомление в Роскомнадзор об обработке персональных данных.
